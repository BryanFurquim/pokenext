## 🧠 Sobre o projeto

**PokeNext** é um projeto desenvolvido durante meus estudos de **Next.js, React e TypeScript**.

A aplicação consome dados da **PokéAPI** para apresentar informações detalhadas sobre cada Pokémon, utilizando rotas dinâmicas e os recursos modernos do **Next.js App Router**.

O projeto também foi utilizado para entender na prática conceitos como:

- Server Components
- Rotas dinâmicas
- TypeScript
- Fetch de APIs
- CSS Modules
- `generateStaticParams`
- `dynamicParams`
- Next/Image
- Tipagem de dados vindos de APIs
